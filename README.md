# SIH 2026 – Adaptive Cold Storage Digital Twin

## Overview

A Digital Twin simulation platform developed for the Smart India Hackathon (SIH 2026) Adaptive Cold Storage concept.

The system models a solar-powered cold storage facility with a movable insulated partition (adaptive shutter) that dynamically adjusts storage volume according to produce load.

## Features

- Dynamic crop database
- Real-time cold storage simulation
- Adaptive partition sizing
- Fuzzy logic control
- Energy consumption analysis
- Cooling load estimation
- Digital Twin visualization
- PyQt5 interactive dashboard

## Technologies

## Problem Statement

Conventional cold storage systems cool unused storage volume, resulting in energy wastage.

This project introduces an adaptive insulated shutter mechanism that dynamically reduces active cooling volume based on produce quantity, improving energy efficiency.

## Applications

- Agricultural cold storage
- Smart warehousing
- Rural food preservation
- Solar-powered refrigeration
